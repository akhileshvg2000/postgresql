1. Set 1: Easy
  1. Assign a row number to each sale ordered by sale_date, with the earliest sale getting rank 1.
  2. Rank sales based on the price of the product in descending order. If two sales have the same price, they should have the same rank.

> [!NOTE]:
>A window function is comes with fun call and an over() followed by.
>over() can have the following cluases included.
> - partition by: To make subset
> - order by    : Can be order by multiple columns
> - rows between/ range between: To specify frame

RANK() OVER(): rank 1 for all rows
RANK() OVER(order by col1): rank for rows with same value for col1 have the same value.
RANK() OVER(order by col1, col2): it is like ditinct. The rows are ordered based on col1 and if col1 have duplicate values, those duplicate rows are again ordered with col2.
                                  So a compination of col1 and col2 will be treated as distinct and have same rank.
  3. Find the total revenue generated by each customer using the SUM() window function.
  4. Determine the number of sales made in each region using a window function.
  5. Find the highest-priced sale for each customer using a window function.

answers
```sql
-- 1. Assign a row number to each sale ordered by sale_date
SELECT sale_id, customer_id, product, sale_date,
       ROW_NUMBER() OVER (ORDER BY sale_date) AS row_num
FROM Sales;

-- 2. Rank sales based on price in descending order
SELECT sale_id, customer_id, product, price,
       RANK() OVER (ORDER BY price DESC) AS price_rank
FROM Sales;

-- 3. Find the total revenue generated by each customer
SELECT sale_id, customer_id, product, price,
       SUM(price * quantity) OVER (PARTITION BY customer_id) AS total_revenue
FROM Sales;

-- 4. Determine the number of sales made in each region
SELECT sale_id, customer_id, region,
       COUNT(*) OVER (PARTITION BY region) AS sales_count
FROM Sales;

-- 5. Find the highest-priced sale for each customer
SELECT sale_id, customer_id, product, price,
       MAX(price) OVER (PARTITION BY customer_id) AS max_price_per_customer
FROM Sales;
```
